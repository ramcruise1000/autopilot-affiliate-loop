# Sample source repo (DEMO ONLY)

A tiny MIT-licensed curated list simulating an "awesome AI tools" repository so you can run this loop locally without network access.

## AI Text & Chat Models

- [OpenAI GPT-4o](https://openai.com/) - The leading multimodal AI model for text and code, available via API or ChatGPT Plus.
- [Anthropic Claude](https://www.anthropic.com/) - Thoughtful, safe AI assistant with strong reasoning capabilities.
- [Grok](https://x.ai/grok) - X's AI chatbot with real-time web access and a rebellious mode.

## Image Generation

- [Midjourney](https://www.midjourney.com/) - High-quality AI image generation, widely used by creatives.
- [Stable Diffusion](https://stability.ai/) - Open-source image model you can run locally or via cloud APIs.
- [Ideogram](https://ideogram.ai/) - Best AI tool for rendering legible text inside images.
- [Playground](https://playground.com/) - Free AI art generator with editing tools for designers.

## Writing Assistants

- [Jasper](https://www.jasper.ai/) - AI writing assistant for marketing copy, blogs, and ad creative.
